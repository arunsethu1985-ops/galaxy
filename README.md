# 🌌 Galaxy

> **A futuristic AI assistant for the web powered by Puter.js.**

Galaxy is a modern browser-based AI assistant that combines intelligent conversations, voice interaction, AI image generation, AI video generation, weather updates, and a premium glassmorphism interface into a single experience.

Built with **HTML, CSS, JavaScript, and Puter.js**, Galaxy runs entirely in the browser and is easy to deploy on platforms like GitHub Pages or Vercel.
