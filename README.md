## 🚀 About Galaxy

Galaxy is a modern AI assistant that runs directly in your browser. It combines conversational AI, voice interaction, AI image generation, AI video generation, live weather, and a beautiful glassmorphism interface into one seamless experience.

Unlike traditional AI chat applications, Galaxy focuses on creating a premium desktop-like experience with animated backgrounds, dynamic themes, smooth transitions, streaming responses, and intelligent media generation.

Whether you want to chat with AI, create artwork, generate videos, or simply explore ideas, Galaxy provides a fast, elegant, and interactive platform.
